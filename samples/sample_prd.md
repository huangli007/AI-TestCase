# 需求文档:智能待办清单 App(示例素材)

## 1. 产品概述

一款面向个人用户的跨平台待办清单 App,支持任务创建、分类管理、提醒通知与数据同步。

- **目标用户**:上班族、学生
- **核心价值**:快速记录任务,智能提醒,多设备同步

## 2. 功能需求

### 2.1 账号模块
- 支持手机号 + 验证码登录,支持微信第三方登录
- 未登录可浏览,登录后才能同步与使用提醒
- 连续输错 5 次验证码需图形验证码校验

### 2.2 任务管理
- 创建任务:标题(必填,最长 100 字)、备注、截止时间、优先级(低/中/高)
- 任务状态:待办 / 进行中 / 已完成 / 已逾期(截止时间超过当前时间自动标记)
- 支持批量删除与批量完成
- 已完成任务默认折叠,可展开查看

### 2.3 分类与标签
- 自定义分类(默认:工作 / 生活 / 学习)
- 每个任务可打多个标签,标签支持按名称搜索

### 2.4 提醒通知
- 任务截止前可设置提醒(提前 5 分钟 / 30 分钟 / 1 小时 / 自定义)
- 支持系统通知、站内提醒
- 应用关闭后提醒仍生效(后台定时任务)

### 2.5 数据同步
- 登录后自动云端同步,支持多设备
- 弱网/断网时本地可编辑,恢复网络后自动合并(以最后修改时间优先)

## 3. 非功能需求

- 兼容 iOS 15+ / Android 10+ 主流机型
- 列表加载分页(每页 20 条)
- 敏感信息(手机号)脱敏展示
- 接口需防注入与越权

## 4. 边界与异常

- 任务标题为空白/超长时校验提示
- 截止时间早于当前时间时创建给出确认
- 并发同步同一任务冲突时以较新版本为准
- 通知权限被拒绝时给出引导
